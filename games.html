Nerf ArenaBlast Level Design

Nerf ArenaBlast is a highly modifiable 1999 Unreal Engine first person arena shooter. I've worked extensively on upgrading and upkeeping the game ever since it became abandonware. In this section, you'll see some of my work in level design and get a look at some of the nuanced theories that go into designing an artistically inspired arena. You can view playlists of my original maps and video comparisons on maps I updated below the image gallery.

Nerf ArenaBlast High Resolution PBR Texture Remakes

As I continue to update the game, I'm able to push the engine more and more. The latest version of the game now supports high resolution physically based rendering. Below you'll see some of my efforts to recreate the tiny, low-detail textures in a new high resolution incarnation but with a familiar style. Re-making these textures presents a gamut of technical challenges; from interpreting artistic intent in small details to removing baked-in lighting.

Nerf ArenaBlast Updater Program

Nerf ArenaBlast never received much official support, but it garnered a fairly large community willing to provide a number of fixes and updates. Installing these updates was a fairly technical and manual process, so I designed a stand-alone updater program to help users keep their game on the bleeding edge of updates. You can view the GitHub repo for this project to see how I've continued to support the community over the years.
